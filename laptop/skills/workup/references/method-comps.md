# Comparable candidates

The workup shortlists and flags. **His verified comps carry the report** — every
table here is a starting point, and the document says so.

## Which sets to build

**Almost every assignment is the first row.** One closed set plus current
competition, and that is the whole job.

| Assignment | Sets |
|---|---|
| **Ordinary 1004, purchase or refinance** — the normal case | closed sales in the subject's segment, plus active and pending competition |
| 2055 / drive-by exterior | same, and say interior condition is unobserved |
| Renovation, 203(k), subject-to-completion — **rare** | adds a second closed set at the finished condition. See the branch at the end of this file |

## Ranking

Sort by strength for **this** assignment, not by distance alone. In order of what
usually matters:

1. Same subdivision or same street
2. Same condition tier as the subject
3. GLA within the band
4. Recency
5. Distance

A same-subdivision sale in the subject's own condition tier beats a closer sale
in a different tier almost every time.

## What each row carries

Address, distance, bed/bath, GLA, year, sale price, $/SF, sale date, days, and a
**remarks angle** — the phrase in the listing that explains where it sits. The
angle is what makes the table usable at a glance: it says why this sale is at
this price.

## The same-subdivision peer set

When the export has several sales inside a short radius, pull them into their own
small table covering every condition tier and both closed and active. A clean
bracket from one subdivision is the strongest thing a screening document can hand
him, and it deserves its own table rather than being buried in the main list.

## Cautions that must travel with a candidate

Never present these as ordinary market transactions:

| Flag | What to write |
|---|---|
| Court-ordered or advertised auction | Not tested by ordinary exposure. Check the legal notice for the advertised exposure period before treating it as market value |
| Multi-parcel sale | The price bought more than one parcel. Verify what it bought before using it |
| Tenant-occupied investor sale | Priced off rent, not off condition. Verify |
| Non-arm's-length or $0 transfer | Report the transfer, never a price |
| Relist | The days figure resets. Use list-to-contract |
| Related-party, estate, or corporate transfer | Verify terms before use |
| Concessions in `SellerParticipation` | Note the amount; it moves the effective price |

A caution is not a reason to drop a sale. It is a reason to verify it, and the
document says which.

## Value indications

Run at least two methods and show them side by side:

- **A** — median $/SF for the subject's segment × GLA
- **B** — the hedonic model, evaluated at the subject's characteristics

Reconcile in a short table: each method's range, the direct comp range, and a
reconciled range. On a purchase, say where the contract price sits relative to it
and why.

**When GLA is unresolved** — the assessor and his measurement disagree — run both
across a GLA range, with the range in the left column so he can find his measured
area. Never pick a single GLA for him.

# The renovation branch — only when the assignment is actually one

Everything below runs only when the order says 203(k), subject-to-completion, or
he says the house is mid-renovation. On an ordinary assignment none of it belongs
in the document, and leading with it answers a question nobody asked.

## As-completed sets

The as-completed set answers a different question: what does this house sell for
finished, in this market. Build it from the renovated tier, weighted hard toward
proximity.

When one sale is the same finished product nearby — same subdivision, same era,
described as the same scope of work — call it out by name as the blueprint for
the assignment and pair it against the best as-is sale. That wreck-to-renovated
pair is independent confirmation of the condition figure from the regression, and
when the two agree it is the strongest support in the document.

## Feasibility, when there are bids

Acquisition price + priced scope = invested. Compare against the reconciled
as-completed range. State the headroom left for the unpriced work, and say what
total scope would exhaust it.

Check what the bids **do not** cover. Exterior bids routinely exclude every
interior item the photographs show as incomplete. Say so explicitly — the
feasibility number is wrong otherwise.
