# What is included in "As-Is Value of Site Improvements" — the list

Two answers live here: the general (textbook/class) list, and the UAD 3.6
rule set, which is now the binding one for GSE work. Where classes have
disagreed over the years, the disagreement is noted with the resolution.

## The UAD 3.6 rules — Appendix F-1, URAR Reference Guide v1.2
(Local copy: Desktop\UAD 3.6\Appendix F-1 URAR Reference Guide v1.2.pdf,
pages 315-317 and Appendix 4. These field IDs are the authority.)

- **25.037 Site Improvement Description** — free-form, one row per item
  OR one aggregated row. F-1's own example list: **"Well, septic, fence,
  driveway and water frontage improvements could be displayed in
  aggregate on a single row, or on separate rows."**
- **25.038 Amount** — the As-Is amount per item as of the effective date;
  individual if documented separately, lump sum if aggregated.
- **25.039 Total** — calculated sum; redisplays at the top of the Cost
  Approach (25.003).
- There is NO enumerated pick-list. The description is free-form. What
  changed in 3.6 is that the report now SHOWS what you included — so the
  workfile buildup and the 25.037 descriptions must match.

### The three routing rules 3.6 adds (this is what settles old arguments)

1. **Detached garage with no additional separate area** → is NOT an
   outbuilding in 3.6. Its depreciated cost goes IN As-Is Value of Site
   Improvements (F-1 note at 25.023 and Appendix 4, Example 1). On the
   old 1004 it rode in the dwelling's garage/carport cost line — this is
   a real change in where the dollars sit.
2. **Outbuildings** (a structure: foundation, walls, roof — detached
   garage WITH additional area, barns, multipurpose buildings) → get
   their OWN Cost Approach subsection (25.023-25.034) with their own
   depreciation. They are NOT site improvements.
3. **Amenity structures without full structure status** (gazebos, outdoor
   kitchens) → reported in Subject Property Amenities, not as
   structures; in the cost approach their contributory value lands in
   site improvements if counted at all.

Attached garages, attached carports, attached porches → inside the
dwelling cost-new. Never in this line.

## The general list (textbook / cost-service "yard improvements")

Include, at contributory (depreciated) value:
- Driveways, parking pads, aprons (asphalt, concrete, gravel)
- Walkways, stoops not in dwelling cost, exterior stairs
- Patios and detached decks (if not priced in dwelling cost-new)
- Fencing and freestanding walls, retaining walls
- FINISH landscaping: lawns, shrubs, trees, irrigation systems
- Detached sheds too minor to be outbuildings
- Swimming pools, hot tubs (in-ground; check they are not in an
  amenities cost line already)
- Wells and septic systems
- Docks, boathouses, water frontage improvements
- Exterior lighting, flagpoles, mailbox structures (minor/misc)

## The classroom disagreements, and where to land

1. **Landscaping — in or out?** Some instructors teach that basic
   grading, drainage, and rough site prep belong in SITE VALUE (the site
   is valued "as improved with utilities and graded"), and only FINISH
   landscaping (lawn, shrubs, trees, irrigation) is a site improvement.
   That split is the defensible line: rough site prep in site value,
   finish landscaping here at contributory value. Never both places.
2. **Utility connections / water & sewer laterals.** Same logic: if the
   site value opinion is for a ready-to-build site (typical), the
   connections are in site value. On well/septic properties the SYSTEMS
   are site improvements — F-1's own example says "well, septic."
3. **Detached garage.** Old argument (dwelling line vs site
   improvements) — 3.6 answered it: no-extra-area detached garage goes
   here. Cite F-1 Appendix 4.
4. **Pools.** Some classes put them with dwelling amenities. If the cost
   service run already carries the pool in an amenity line, do not
   repeat it here. One place only.
5. **"As-is" means depreciated contributory value**, not cost new and
   not cost-to-replace — the old forum argument. The line's own name
   answers it; F-1's definition ("value contributed") confirms.

## The one-sentence rule that survives every version of the argument

Every dollar on the property appears in exactly one cost-approach bucket:
site value, dwelling cost-new, outbuilding subsection, or this line.
Pick the bucket by what the site value opinion assumed and what the cost
service run already included — then say in the workfile which bucket got
what.
